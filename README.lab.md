# Anti-Cheat Lab

An offline game based on Red Eclipse, not affiliated with the Red Eclipse project.
This modified fork is only for local bot matches in SUMMERxKx/anti-cheat.
Remote play, LAN discovery, join links, Steam and Discord are removed in LAB_BUILD.
The protocol and home directory differ from Red Eclipse.

Build through the parent anti-cheat repository with LAB_BUILD on.
Upstream code and data retain their original licences.
